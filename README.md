# Carnet Seyès

Carnet de notes installable sur téléphone et ordinateur : pages titrées, texte mis en forme, images, tableaux, vidéos, PDF, notes en marge, post-it et dessin (stylo, marqueur, crayon, gomme, formes). Fonctionne hors connexion.

**Ouvrir et installer :** https://27gaelle82.github.io/carnet-seyes/

- iPhone / iPad : dans Safari, Partager → « Sur l'écran d'accueil ».
- Android : dans Chrome, menu ⋮ → « Installer l'application ».
- Ordinateur : dans Chrome ou Edge, icône d'installation dans la barre d'adresse.

Les notes sont enregistrées sur l'appareil (IndexedDB), jamais sur ce dépôt. Le bouton « Sauvegarder » exporte tout dans un fichier `.json` qu'on peut réimporter ailleurs.

Le lecteur PDF fourni dans `vendor/pdfjs` est [PDF.js](https://github.com/mozilla/pdf.js) (licence Apache 2.0).
